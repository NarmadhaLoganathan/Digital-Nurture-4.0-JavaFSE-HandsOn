#  EventExamplesApp - React Event Handling Lab

A simple React app that demonstrates how to handle events in React using buttons, synthetic events, function arguments, and form inputs.

---

##  Features

-  Increment and Decrement counter buttons
- `Increment` button calls multiple methods (counter + alert)
- `Say Welcome` button with function argument
-  Synthetic event handler with message on click
-  Currency converter: Converts INR to Euro on button click

---

##  Concepts Covered

- React Events
- Event Handlers
- Synthetic Events
- `this` keyword in functional components (via arrow functions)
- Passing arguments to event handlers
- JSX with condition and state handling

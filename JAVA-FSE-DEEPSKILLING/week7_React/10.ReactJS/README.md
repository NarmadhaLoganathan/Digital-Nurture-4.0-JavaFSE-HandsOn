# Office Space Rental App

A simple React application that displays available office spaces using **JSX**, **JavaScript expressions**, and **inline CSS styling**.

---

## Features

- Display heading and office image using JSX
- Show office space details (Name, Address, Rent)
- Use conditional styling for Rent:
  - Red if below ₹60,000
  - Green if ₹60,000 or above
- Neat and centered card layout

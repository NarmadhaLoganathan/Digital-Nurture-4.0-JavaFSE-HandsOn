#  Mail Register App – React Form Validation

This React application demonstrates how to implement **form validation** using controlled components and handle form input and submission properly in React.

---

##  Features

-  Input fields: **Name**, **Email**, **Password**
-  Validates input on form **submit**
-  Displays error messages below invalid fields
-  Password must be at least 8 characters
-  Email must include `@` and `.`
-  Name must be at least 5 characters
-  Clears form and shows success alert on valid submission

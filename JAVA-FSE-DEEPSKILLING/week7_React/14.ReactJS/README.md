# Employee Theme Context App

This is a simple React application that demonstrates how to use the **React Context API** to apply **light** and **dark themes** across nested components — without using props.

---

## Features

-  Toggle between **Light** and **Dark** themes
-  Uses **React Context API** to avoid prop drilling
-  Displays a list of employees with themed buttons
-  Clean and modular code using multiple components

---

## Concepts Covered

- `createContext()` and `useContext()` hooks
- Context Provider and Consumer usage
- Conditional className for theming
- React functional components
- CSS styling for theme switching

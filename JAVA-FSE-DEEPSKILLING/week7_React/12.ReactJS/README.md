# TicketBookingApp - React Conditional Rendering

This is a simple React application that demonstrates **conditional rendering** based on the user's login state.

---

##  Features

- Displays flight details for both guest and logged-in users
- Conditional UI:
  - Shows **Login** button and guest message if not logged in
  - Shows **Logout** button and booking info if logged in
- Uses element variables and `useState` to control what is rendered

---

##  Concepts Covered

- Conditional Rendering in React
- Element Variables
- Preventing Components from Rendering
- React `useState` hook

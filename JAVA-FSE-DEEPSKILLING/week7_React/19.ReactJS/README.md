#  GitHub Client App

This is a simple React application that uses **Axios** to fetch and display public GitHub repositories of a specific user (e.g., `techiesyed`). It also includes a unit test using **Jest** with mocked Axios.

---

##  Features

- Fetches repositories from GitHub using Axios
- Displays repo names in a styled list
- Unit test to check API call with mock data
- Clean and responsive UI

---

## Technologies Used

- React
- Axios
- Jest (for testing)

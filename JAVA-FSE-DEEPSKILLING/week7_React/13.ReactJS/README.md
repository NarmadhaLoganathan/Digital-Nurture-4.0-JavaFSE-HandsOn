#  BloggerApp – Conditional Rendering & Component Layout in React

This is a React application that demonstrates how to:
- Extract reusable components
- Render lists using `.map()`
- Apply conditional rendering styles
- Build a clean, structured **3-column layout** using **Flexbox**

---

##  Features

-  **Book Details** – List of books with title and price
-  **Course Details** – Courses with their respective dates
-  **Blog Details** – Blog title, author, and description
-  Organized into 3 visually separated columns
-  Fully responsive layout using Flexbox
-  Keys used in `.map()` for efficient rendering

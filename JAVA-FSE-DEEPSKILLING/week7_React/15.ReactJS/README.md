#  Ticket Raising App

This is a simple React application that allows employees to **raise complaints** using a form. On form submission, the app generates a **reference number** and displays it via an alert.

---

##  Features

-  Controlled form inputs using `useState`
-  Textbox for employee name
-  Textarea for complaint description
-  `handleSubmit()` prevents default form behavior
-  Random reference number is generated for tracking

---

##  Concepts Covered

- React Forms and Input Handling
- Controlled Components (`useState`)
- Form Submission Handling
- JSX and Basic Component Design
- Dynamic Alert Messages
